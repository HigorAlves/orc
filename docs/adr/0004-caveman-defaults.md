# 0004 — Caveman output by default

- **Status:** Accepted
- **Date:** 2026-08-20
- **Deciders:** maintainer

## Context

PR bodies, review comments, reply drafts, and commit bodies generated by a model default to the long form: a tour of the diff, a paragraph per finding, praise before the problem. Reviewers skim them, and the signal (why, how tested, what could go wrong) is buried in restatement. The 0.20.0 train (#82, #83) made the terse register the default and moved the long form behind `--verbose`.

## Decision

Commit bodies, PR bodies, review comments, and replies are written in the caveman register: terse, signal-only, no throat-clearing, no praise, no restating what the diff shows. GitHub's renderer carries structure instead of words: auto-linked refs, line permalinks, fenced code with a language, `<details>` for bulk, suggestion blocks for exact fixes. Long form is opt-in (`--verbose`) and is never the default. Security findings, architectural disagreements, and one-way doors drop terse mode because they need the why.

## Alternatives considered

### Option A — Long-form templates by default, terse on request
- The conventional shape; richer first impression.
- Rejected: the maintainer's own PRs were being skimmed past the part that mattered; the long form costs the reader more than it gives.

### Option B — Terse everywhere, no escape hatch
- Rejected: migrations, security fixes, and multi-team reviews need narrative; 0.26.0 added a mandatory merge-danger line for exactly those.

## Consequences

- **Positive:** a PR body fits on one screen; a review comment is one line with a fix; the reviewer's time goes to the diff.
- **Negative:** terse reads as curt to people who expect the long form; the register is a house style, not a universal one.
- **Neutral:** `orc:caveman-pr`, `orc:caveman-review`, and `orc:git-commit` own the register; `orc:callouts` adds the GitHub `[!TYPE]` tags only in GitHub-bound output.

## Follow-ups

- [x] Merge danger (door + blast radius) added as a required line for non-trivial PRs (0.26.0).
